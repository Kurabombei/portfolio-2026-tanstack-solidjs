# 🚀 Full Stack Engineer Portfolio

A blazing-fast, mobile-first portfolio built with **TanStack Start** and **SolidJS**.

## 🛠 Tech Stack
- **Framework:** TanStack Start (SSR, File-based routing)
- **UI Library:** SolidJS (Fine-grained reactivity, no VDOM)
- **Styling:** SCSS + CSS View Transitions API (Native browser animations)
- **Icons:** Lucide / Custom SVG logos

## ✨ Features
- **Bento Grid Design:** Modern, scannable layout.
- **App-like Feel:** Cross-document transitions using the native View Transitions API.
- **SEO Optimized:** SSR-rendered meta tags and semantic HTML.
- **100% Lighthouse Score Target:** Minimal JS payload.

## 📦 Installation & Setup

1. Clone the repository:
    git clone <repo-url>
    cd portfolio

2. Install dependencies:
    npm install

3. Run the development server:
    npm run dev

4. Open http://localhost:3000 to view it in the browser.

## 📁 Project Structure
- /app/routes/ - TanStack file-based routes
- /app/components/ - Reusable SolidJS components (e.g., HeroGrid.tsx, TechCard.tsx)
- /app/styles/ - Global SCSS and view transition rules
- /app/data/ - JSON or TypeScript files holding resume data
